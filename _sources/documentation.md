# Modes de documentation

Le travail documentaire attendu consiste à rassembler et vérifier les informations nécessaires à l’acquisition des notions de Physique demandées 
dans le projet en combinant trois modes de documentation :
1. Ouvrages papier de la bibliothèque universitaire
2. Ressources en ligne (wikipedia, organismes scientifiques ou journaux)
3. Agent d'intelligence artificielle


```{Attention}
Ni les vidéos, ni les sites personnels, quel·le qu'en soit l'auteur·rice, ne seront acceptés comme sources valides.
```

Pour chaque source (livre, site ou réponse à une requête), les informations obtenues sont rassemblées dans une **fiche de lecture**.
Le premier document à rendre est structuré par les différentes sources
documentaires (informations issues de la source 1, informations issues
de la source 2, *etc.*)

Chaque mode de documentation est pris en charge par une sous-équipe de 2 ou 3 membres identifiés au début du projet.
Les fiches de lecture de chaque mode seront rendues et évaluées séparément.


```{Attention}
Toute information, qu'elle soit correcte ou non, ne figurant pas dans une fiche de lecture ne sera pas prise en compte à l'oral.
```

Le second document à rendre est une **synthèse de cours**. 
Les explications doivent y être assez claires pour que l’on puisse les
comprendre sans devoir lire soi-même les sources documentaires.
